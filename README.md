Проект посвящен глубокому изучению и реализации линейных моделей машинного обучения для задачи регрессии. В рамках работы были выведены аналитические формулы, реализованы с нуля (на чистом NumPy в ООП-стиле) основные алгоритмы оптимизации и регуляризации, а также проведено сравнение разработанных моделей с де-факто стандартными классами из библиотеки scikit-learn. Все решение реализовано в jupyter-ноутбуке в src/decision.py

📋 Содержание проекта

1. Теоретическая база (п. 1.1 — 1.4):
	• Матричный аналитический вывод формулы оптимальных весов для OLS (МНК).
	• Математическое обоснование изменения решения при добавлении L₁ (Lasso) и L₂ (Ridge) регуляризаций, а также их комбинации (ElasticNet).
	• Геометрическая интерпретация того, почему регуляризация Lasso приводит к разреженности весов и может использоваться для отбора признаков.
	• Способы применения линейных моделей для нелинейных зависимостей (полиномиальные признаки, функциональные преобразования).
2. Предобработка данных (п. 2.0):
	• Очистка данных, фильтрация аномалий (выбросов) по квантилям.
	• Парсинг текстовых тегов и конструирование бинарных признаков (One-Hot Encoding вручную) с помощью collections.Counter.
3. Реализация моделей с нуля (п. 4.0 — 5.0):
	• MyLinearRegressionAnalytic — аналитическое решение через нормальное уравнение.
	• MyGDLinearRegression — классический градиентный спуск (Full GD).
	• MySGDLinearRegression — стохастический градиентный спуск с генератором случайных чисел (Random Seed) для обеспечения детерминированности траектории.
	• MyRidgeAnalytic — гребневая регрессия с аналитическим решением (без штрафа на свободный член).
	• MyElasticNetGD & MyLassoGD — численный расчет регуляризованных моделей на основе субградиентного спуска.
4. Метрики и Валидация (п. 4.0):
	• Собственные реализации функций оценки качества: MAE, RMSE и R² (коэффициент детерминации).
5. Масштабирование признаков (п. 6.0):
	• Кастомные классы MyMinMaxScaler и MyStandardScaler (с защитой от деления на ноль). Обоснование важности нормализации для градиентных методов и регуляризации.
6. Эксперименты и Бонусная часть:
	• Исследование эффекта переобучения на полиномах высокой степени (10-я степень).
	• Подбор гиперпараметра α (компромисс смещения и разброса).
	• Реализация наивных бейзлайнов (MyNaiveRegressor по среднему и медиане).
	• MyMiniBatchGD — мини-пакетный градиентный спуск, исследование влияния размера батча на скорость сходимости и качество.
	• Эксперименты с логарифмированием скошенного таргета (\(\log(y)\)).

📊 Итоговые результаты

В ходе тестирования наилучшие результаты на тестовой выборке показала модель Lasso регрессии в сочетании с MinMaxScaler (\(R^2_{test} \approx 0.5653\), \(R^2_{train} \approx 0.5848\)), продемонстрировав минимальный разрыв (gap) между обучающей и валидационной выборками, что говорит об отсутствии переобучения. Все кастомные NumPy-модели сошлись к результатам аналогов из scikit-learn с машинной точностью (до 10⁻¹²).
